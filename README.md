# דף נחיתה לעסק מזגנים

דף נחיתה בעברית (RTL) שכל המטרה שלו היא להביא פניות לוואטסאפ. HTML, CSS ו-JS נקיים, בלי שלב build. האנימציות ב-GSAP.

## מבנה

```
index.html            הדף עצמו: כל הסקשנים
accessibility.html    הצהרת נגישות (להשלים את הפרטים בסוגריים)
assets/css/style.css  עיצוב, צבעים, רספונסיביות
assets/js/config.js   כל פרטי העסק במקום אחד
assets/js/main.js     אנימציות, טופס→וואטסאפ, ספירה לאחור, קרוסלה
netlify.toml          הגדרות אחסון ל-Netlify
docs/client-brief.md  שאלון הפרטים שצריך מבעל העסק
```

## צפייה מקומית

```bash
python3 -m http.server 8000
```

ואז לפתוח את http://localhost:8000

## עריכת פרטים

כמעט הכול נמצא ב-`assets/js/config.js`: שם העסק, טלפון, מספר וואטסאפ, הודעה מוכנה, אזורי שירות, שעות, מבצע ומזהי מעקב. כל שינוי שם מתעדכן בכל המקומות בדף.

הטקסטים השיווקיים (שירותים, יתרונות, המלצות, שאלות נפוצות) כתובים ישירות ב-`index.html`.

## הוספת תמונות

כל מקום לתמונה מסומן ב-`data-photo`. מוסיפים בתוכו תגית `<img>` והיא מכסה את המקום השמור:

```html
<div class="photo-slot" data-photo="service-install">
  <img src="assets/img/service-install.webp" alt="טכנאי מתקין מזגן עילי בחדר שינה" loading="lazy" width="1200" height="900">
</div>
```

עדיף WebP ברוחב של עד 1600px.

## לפני העלייה לאוויר

- [ ] `previewMode: false` ב-`config.js` (מסתיר את פס הטיוטה)
- [ ] להחליף את כל הערכים בסוגריים מרובעים, כולל מספר הוואטסאפ
- [ ] להחליף את המספרים בסקשן "למה אנחנו" ובדירוג בגוגל במספרים אמיתיים
- [ ] להחליף את ההמלצות בהמלצות אמיתיות
- [ ] מבצע: לעדכן או לכבות (`promo.enabled: false`)
- [ ] להוסיף תמונות במקומות השמורים
- [ ] להשלים את `accessibility.html`
- [ ] לעדכן את ה-title וה-description ב-`index.html`

## העלאה ל-Netlify

מחברים את המאגר ב-Netlify (Add new site → Import from Git). אין פקודת build, ותיקיית הפרסום היא השורש (מוגדר ב-`netlify.toml`).
